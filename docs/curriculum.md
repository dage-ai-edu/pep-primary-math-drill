# 人教版小学数学计算关卡对照

## 编排原则

本项目依据用户提供的 12 册人教版小学数学教材目录与计算章节编排。教材均位于：

`/Users/mengjuan/Desktop/桌面暂存箱/小学/数学/人教版`

核对时以各册 PDF 的目录页（PDF 第 5—6 页）和对应单元为依据。游戏只选择适合数字输入训练的计算内容；图形、测量、统计、位置、综合实践和开放性应用题不强行改造成口算题。

## 关键调整

- 二年级不设置任何分数关卡。
- 分数从三年级上册“分数的初步认识”开始。
- 一位小数加减放在三年级下册，小数加减完善放在四年级下册。
- 小数乘除和简易方程放在五年级上册。
- 因数、倍数、约分、通分和分数加减放在五年级下册。
- 分数乘除和百分数放在六年级上册。
- 百分数应用、比和比例放在六年级阶段。

## 学期对应

### 一年级

- 上册：5 以内、6—10 的认识和加减，连加连减，20 以内进位加法。
- 下册：20 以内退位减法，100 以内数的认识与加减。

### 二年级

- 上册：1—6 和 7—9 的表内乘除。
- 下册：有余数除法，万以内数的加减。
- 明确排除：分数、小数、百分数。

### 三年级

- 上册：混合运算，多位数乘一位数，分数的初步认识。
- 下册：除数是一位数的除法，两位数乘两位数，小数的初步认识。

### 四年级

- 上册：多位数乘两位数，除法和商不变的规律，近似数。
- 下册：四则运算、运算律、小数的意义和性质、小数加减。

### 五年级

- 上册：小数乘法、小数除法、用字母表示数和简易方程。
- 下册：因数和倍数、分数的意义和性质、分数加减。

### 六年级

- 上册：分数乘法、分数除法、百分数。
- 下册：百分数应用、比例及相关计算。

## 实现边界

`app/js/skills.js` 是唯一的关卡课程表；`app/js/problems.js` 负责生成题目。任何年级调整都必须同时通过：

1. 技能年级与前置关系检查；
2. 所有生成器的答案和输入步骤检查；
3. 技能树布局检查；
4. 二年级不存在分数技能的专项检查。
